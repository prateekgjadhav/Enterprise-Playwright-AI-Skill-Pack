# Agent instructions

The same instructions apply to every agent tool working in this repository. Read and follow
[`CLAUDE.md`](CLAUDE.md): it holds the setup-first onboarding (`project-setup` runs on an
unfamiliar repo), the eight-step workflow, the routing table, the non-negotiables (governance,
defensive/authorised-only security, evidence-based risk work, secret hygiene), and the evidence block that every reply ends
with. Project-specific values live in `.agents/qa.config.json`, never in the skills.
